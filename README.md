# 🏠 RentMate - Премиум Платформа Аренды Жилья

Современная премиум платформа для поиска жилья и соседей в Бишкеке, Кыргызстан. Создана с использованием React, TypeScript и Tailwind CSS v4.

![RoomMate Platform](https://img.shields.io/badge/React-18.3.1-blue)
![TypeScript](https://img.shields.io/badge/TypeScript-5.5.3-blue)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-4.1.12-cyan)

## ✨ Особенности

- 🎨 **Премиум дизайн** - Темно-зеленая цветовая палитра с glassmorphism эффектами
- 🔍 **Умный поиск** - Поиск по названию и локации с динамическими фильтрами
- ❤️ **Избранное** - Сохранение понравившихся квартир
- 🤖 **AI Ассистент** - Встроенный чат-помощник для каждой квартиры на русском языке
- 📱 **Responsive** - Полностью адаптивный дизайн для всех устройств
- ⚡ **Быстрая работа** - Построено на Vite для максимальной производительности
- 🎭 **Плавные анимации** - Используется Motion для красивых переходов
- 🇰🇬 **Адаптация под Кыргызстан** - Локации Бишкека, цены в сомах, русский интерфейс
- 🏠 **Управление объявлениями** - Добавляйте, редактируйте и удаляйте свои квартиры

## 🚀 Быстрый старт

### Установка

```bash
# Клонируйте репозиторий или скопируйте файлы
cd roommate-platform

# Установите зависимости (рекомендуется pnpm)
pnpm install
# или
npm install
```

### Запуск

```bash
# Режим разработки
pnpm dev
# или
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

### Сборка для продакшена

```bash
pnpm build
# или
npm run build
```

## 🎯 Основные функции

### 🏡 Просмотр квартир
- Карточки квартир с фото, ценой, рейтингом
- Детальная информация о каждой квартире
- Галерея изображений
- Информация о владельце

### 🔍 Поиск и фильтры
- Поиск по названию и описанию
- Фильтр по локации
- Диапазон цен (слайдеры)
- Количество комнат
- Минимальный рейтинг
- Тип жилья (квартира, комната, студия, дом)
- Допуск питомцев
- Предпочтение по полу

### 💬 Коммуникация
- AI чат-ассистент с готовыми ответами
- Система сообщений
- Уведомления

### 👤 Профиль пользователя
- История аренды
- Статистика (объявления, избранное, отзывы)
- Настройки

### ➕ Добавление объявлений
- Форма с валидацией
- Добавление удобств
- Загрузка изображений (UI готов)

## 🎨 Технологии

## 🌈 Цветовая схема

Платформа использует премиум темно-зеленую палитру:

- **Primary**: Deep Emerald Green (#0f4c3a)
- **Secondary**: Forest Green (#064e3b)
- **Accent**: Light Green (#d4e8e0)
- **Background**: White (#ffffff)
- **Text**: Dark Gray (#1a1a1a)
