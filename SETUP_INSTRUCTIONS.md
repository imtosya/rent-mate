# RoomMate - Premium Housing Platform

## Полная инструкция по установке и запуску

### 1. Создайте новый проект

```bash
mkdir roommate-platform
cd roommate-platform
```

### 2. Инициализируйте проект

```bash
npm init -y
```

### 3. Установите все зависимости

Скопируйте `package.json` из этого проекта и выполните:

```bash
pnpm install
```

Или если у вас npm:

```bash
npm install
```

### 4. Структура проекта

Создайте следующую структуру папок и файлов:

```
roommate-platform/
├── src/
│   ├── app/
│   │   ├── components/
│   │   │   ├── Navbar.tsx
│   │   │   ├── HeroSection.tsx
│   │   │   ├── PropertyCard.tsx
│   │   │   ├── PropertyDetailModal.tsx
│   │   │   ├── FilterPanel.tsx
│   │   │   ├── AIChatAssistant.tsx
│   │   │   ├── UserProfile.tsx
│   │   │   ├── ListPropertyForm.tsx
│   │   │   ├── FavoritesView.tsx
│   │   │   ├── MessagesView.tsx
│   │   │   └── NotificationsView.tsx
│   │   ├── types.ts
│   │   └── App.tsx
│   └── styles/
│       ├── theme.css
│       └── fonts.css
├── package.json
├── vite.config.ts
├── tsconfig.json
└── index.html
```

### 5. Файлы конфигурации

**vite.config.ts**
**tsconfig.json**
**index.html**

Все эти файлы уже должны быть в проекте.

### 6. Запуск проекта

```bash
npm run dev
```

Или с pnpm:

```bash
pnpm dev
```

Проект будет доступен по адресу: http://localhost:5173

### 7. Основные возможности платформы

✅ **Навигация** - Полностью рабочая навигация между разделами
✅ **Поиск** - Работающая поисковая система по названию и локации
✅ **Фильтры** - Динамические фильтры (цена, комнаты, рейтинг, тип, питомцы, пол)
✅ **Избранное** - Система сохранения избранных квартир
✅ **AI Чат** - Встроенный AI ассистент для каждой квартиры
✅ **Детали квартиры** - Модальные окна с полной информацией
✅ **Профиль пользователя** - Страница профиля с историей аренды
✅ **Сообщения** - Раздел сообщений
✅ **Уведомления** - Система уведомлений
✅ **Добавление квартиры** - Форма для добавления новых объявлений
✅ **Отзывы и рейтинги** - Система отзывов для каждой квартиры
✅ **Responsive дизайн** - Адаптивный дизайн для всех устройств

### 8. Дизайн

## Поддержка

При возникновении проблем:
1. Убедитесь, что установлены все зависимости
2. Проверьте версию Node.js (рекомендуется 18+)
3. Очистите кэш: `rm -rf node_modules package-lock.json && npm install`
